# Sample Data

The files contained in the [/data](/data) directory contain examples of file types that are common to DH projects. Explore the files in these folders. Explore these files on GitHub's website. If available, click "code" at the top of an open file to see how they are formatted as plain text.

# [data/cantus-index_cantuscorpus_2.0/static](data/cantus-index_cantuscorpus_2.0/static)

This folder contains metadata stored as CSV files from [Cantus Index](https://cantusindex.org/)'s  GitHub, [CantusCorpus](https://github.com/dact-chant/CantusCorpus). CSV files store tabular data as plain text which can be open with spreadsheet applications like Google Sheets or Excel and understood by programming languages like Python.

# [data/measuring-polyphony_music](data/measuring-polyphony_music)

[The xml_files folder](./xml_files) contains music encoded as XML files from the [Measuring Polyphony](https://measuringpolyphony.org/) project. XML files are a common way to encode information (like text and music) so it is both human- and machine-readable.

[music_metadata.json](./music_metadata.json) contains metadata of the music in [xml_files](./xml_files) as a JSON file. JSON stands for **J**ava**S**cript **O**bject **N**otation, a file format commonly used for transferring data.
