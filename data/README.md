# Sample Data

The ["data"](/data) directory contains examples of file types that are common to DH projects. Explore the files in these folders to see how these they are formatted (open them in Notepad/TextEdit or on GitHub online).

# [/data/cantus-index_cantuscorpus_2.0/static](/data/cantus-index_cantuscorpus_2.0/static)

This directory contains metadata stored as CSV files from [Cantus Index](https://cantusindex.org/)'s GitHub, [CantusCorpus](https://github.com/dact-chant/CantusCorpus). CSV files store tabular data as plain text which can be opened with spreadsheet applications like Google Sheets or Excel or read/written using languages like Python.

# [/data/measuring-polyphony_music](/data/measuring-polyphony_music)

The ["xml_files"](/data/measuring-polyphony_music/xml_files) directory contains music encoded as XML files from the [Measuring Polyphony](https://measuringpolyphony.org/) project. XML files are a common way to encode information (like text and music) so it is both human- and machine-readable.

["music_metadata.json"](/data/measuring-polyphony_music/music_metadata.json) contains metadata of the music in ["xml_files"](/data/measuring-polyphony_music/xml_files) as a JSON file. JSON stands for **J**ava**S**cript **O**bject **N**otation, a file format commonly used to store/exchange data. It is commonly used in web development with JavaScript.
