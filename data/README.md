# Sample Data

The files contained in the [/data](/data) directory contain examples of file types that are common to DH projects. 

# [/cantus-index_cantuscorpus_2.0/static](/cantus-index_cantuscorpus_2.0)

The files are taken from [Cantus Index's](https://cantusindex.org/) GitHub, [CantusCorpus](https://github.com/dact-chant/CantusCorpus). This resource is devoted to the study of medieval chant texts and melodies. 

This folder contains metadata stored as CSV files. Open a file to explore! Click "code" to see how these files are formatted as plain text.

# [/measuring-polyphony_music](measuring-polyphony_music)

The files in this folder are taken from the [Measuring Polyphony](https://measuringpolyphony.org/) project which provides encodings of fourteenth-century medieval music. [/measuring-polyphony_music/xml_files](/measuring-polyphony_music/xml_files) contains Measuring Polyphony XML files. XML files are a common way to encode information in a way that is both human- and machine-readable. Both music and text are commonly encoded as XML files. Open a file to explore! Click "code" to see how these files are formatted as plain text.
